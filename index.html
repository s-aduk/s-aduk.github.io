SHEET 01 / PROFILE

Systems thinking,
grounded in code.

I'm a Cloud Native Developer and Computer Science graduate from KNUST, focused on designing and shipping event-driven, serverless systems on AWS.

My core work right now is SentryNode, a fraud detection engine that reacts to transactions in real time: API Gateway takes the request, SQS holds the load, Lambda evaluates risk, DynamoDB stores state, SNS fires the alert. MediFind, a real-time pharmacy finder, runs on the same serverless discipline.

Before this, I spent a year inside GCB Bank PLC's digital operations: debugging live banking platforms, routing support tickets, and learning what production actually demands when the stakes are real money.
